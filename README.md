# information-system-for-online-service-booking
# Автоматизированная информационная система онлайн-бронирования услуг СОК «Калининец»

### Описание проекта
Данный проект представляет собой автоматизированную информационную систему (АИС) для управления и онлайн-бронирования услуг спортивно-оздоровительного комплекса «Калининец». Проект разработан в рамках курсовой работы по дисциплине «Алгоритмизация и программирование».

**Основная цель:** автоматизация процесса записи клиентов на спортивные услуги, минимизация ошибок при распределении временных слотов и защита пользовательских данных.

---

### Ключевой функционал
* **Управление бронированием:** выбор спортивных зон (бассейн, тренажерный зал, корты) и доступных временных слотов.
* **Алгоритм валидации:** проверка наложения сессий (предотвращение бронирования одного слота разными пользователями).
* **Управление очередью:** динамическое распределение заявок при отмене брони.
* **Безопасность (AppSec):** валидация и фильтрация входящих данных для защиты от базовых инъекций, безопасное хранение локальных сессий.

---

### Стек технологий
* **Язык разработки:** Python 3
* **Архитектурный шаблон:** MVC (Model-View-Controller)
* **Инструменты:** Git, ООП-моделирование данных, алгоритмы поиска и сортировки временных интервалов.
